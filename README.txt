사진조각 PC 실행 방법

1. 이 폴더를 C:\code\photo-piece 위치에 압축 해제합니다.
2. 실행.bat을 더블클릭합니다.
3. Python이 설치되어 있으면 http://localhost:8080 주소로 실행됩니다.
4. Python이 없어도 index.html을 직접 열어 실행할 수 있습니다.

포함 파일
- index.html: 웹 화면 구조
- style.css: 디자인
- app.js: 퍼즐 생성 및 조작 기능
- favicon.svg: 사이트 아이콘
- 실행.bat: Windows 실행 파일

예제 사진을 불러오려면 인터넷 연결이 필요합니다.
내 사진 업로드와 퍼즐 기능은 PC에서 처리됩니다.
